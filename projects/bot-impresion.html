Bot de impresión automática

Automatización del procesio de impresión y gestión de documentos PDF mediante Python.

Python Watchdog PyWin32 Automation

Objetivo

Crear una solución capaz de detectar nuevos documentos, enviarlos automáticamente a impresión y organizar los archivos procesados.

Tecnologías utilizadas

  • Python
  • Watchdog para monitoreo de archivos
  • PyWin32 para interacción con Windows
